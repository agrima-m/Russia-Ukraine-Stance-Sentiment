# Decoding Perspectives in the Russia-Ukraine Conflict: A Comparative Study of RNN, LSTM, TCN and BERT Models for Stance Detection and Sentiment Analysis

A comparative study evaluating **Simple RNN**, **LSTM**, **Temporal Convolutional Networks (TCN)**, and **BERT** for stance and sentiment classification on a large-scale Twitter dataset related to the Russia–Ukraine conflict.

---

## 📌 Overview

This project investigates how different deep learning architectures perform on stance and sentiment classification under a common preprocessing and evaluation framework. The study compares recurrent, convolutional, and transformer-based models to identify their strengths, limitations, and suitability for NLP classification tasks.

---

## 🎯 Objectives

- Compare RNN, LSTM, TCN, and BERT architectures.
- Evaluate performance on stance and sentiment classification.
- Analyse the impact of model architecture on classification accuracy.
- Benchmark traditional deep learning models against transformer-based approaches.

---

## 📊 Dataset

- **Dataset:** *Unveiling Global Narratives: A Large-Scale Multilingual Dataset of Tweets on the Russia–Ukraine Conflict* (Proceedings of the ACM International Conference on Multimedia Retrieval (ICMR 2024))
- **Size:** 1.52 million tweets
- **Languages:** 60
- **Tasks:** Stance Classification and Sentiment Analysis

---

## 🤖 Models Compared

| Model | Purpose |
|--------|---------|
| Simple RNN | Baseline sequential model |
| LSTM | Long-term dependency modelling |
| TCN | Dilated temporal convolutions |
| BERT | Transformer-based contextual model |

---

## 📈 Evaluation

Models were compared using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The comparison focuses on predictive performance, robustness to class imbalance, and computational efficiency.
